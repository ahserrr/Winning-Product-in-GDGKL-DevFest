# Winning-Product-in-GDGKL-DevFest

A clean, conversion-focused welcome page for Deriv built for GDG KL DevFest Hackathon.

## Features
- **Zero build step**: Pure static single file (`index.html`) using Tailwind CSS via CDN and vanilla JavaScript.
- **Conversion-focused UX**: Answers what the product does, who it's for, and what to do next within 5 seconds.
- **Interactive "Is this for me?" Quiz**: 3 questions guiding users to personalized paths (Beginner Guides, Demo, or Real Account).
- **Mobile-first & Accessible**: Fully responsive down to 375px with semantic HTML and keyboard navigation.
